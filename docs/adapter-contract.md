# RagSentry Adapter Contract

RagSentry interacts with target RAG applications strictly as black boxes through an **Adapter**.

## Contract Specification

Any adapter must accept a question string and return an `AdapterResponse`:

```python
query(question: str) -> AdapterResponse
```

### Response(`AdapterResponse`) Schema

| Field        | Type                | Description                                                  |
| ------------ | ------------------- | ------------------------------------------------------------ |
| `answer`   | `str`             | The answer string generated by the RAG system.               |
| `contexts` | `list[str]`       | The text chunks/passages retrieved to generate the answer.   |
| `metadata` | `dict` (optional) | Arbitrary diagnostic metadata (e.g. latency, model, tokens). |
